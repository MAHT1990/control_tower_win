### 2-1. 신규 FR-046 — 탭·터미널 표시 이름 변경 [TRM · Should · L0]

### 2-7. 신규 FR-047 — 터미널 간 출력 라우팅 (A→B 활용) [SES · Should]

캡처(FR-002)와 주입(FR-014)은 각각 있으나, **A의 출력을 캡처해 B(또는 다수)의 입력으로 전달·활용**하는 연결은 스펙에 없다. SC-09(선택 복사→붙여넣기 주입)는 클립보드 경유 **수동 원시형**뿐 → 오케스트레이션 능력으로 승격(제품 1차 정체성: 세션 간 협업 — IPC 파일 채널과 별개의 **raw 출력 라우팅**).

- **설명**: 한 세션(A)의 출력(마지막 명령 결과·선택 영역·스트림)을 캡처해 다른 세션(B/다수)의 입력으로 라우팅한다.
- **메커니즘 확정: (c) 캡처 버퍼 + 가공 후 주입** — A 출력을 앱 **캡처 버퍼**에 수집 → 사용자가 버퍼를 뷰·편집(가공) → 대상 세션(B/다수) 입력으로 주입. ((a)스냅샷·(b)라이브 파이프 `A | B`는 후속 승격.)
- **핵심 흐름**:
```
[A 세션 출력] --캡처(선택/마지막명령/스트림)--> [앱 캡처 버퍼(편집 가능 텍스트)]
                                                     │ 사용자 뷰·편집(가공)
                                                     ▼
                                        [대상 세션 선택(B/다수)] --주입--> [B 입력]
```
- **AC**:
  - A 세션의 출력(선택 영역 / 마지막 명령 결과 / 스트림 청크)을 캡처 버퍼에 적재
  - 버퍼 내용을 패널에서 뷰·편집 가능(가공 단계)
  - 대상 세션(단일/다수) 선택 후 주입 — 대상 명시(오주입 방지), 위험 패턴이면 SC-13 게이트 경유
  - 다수 대상은 각 세션 입력에 독립 주입 / 캡처 버퍼는 런타임(재시작 시 소멸)
- **airspace 정합**: 캡처 버퍼 패널은 터미널 native 존 **밖** 별도 패널(07:334 "출력 로그는 터미널 존 밖 별도 패널" 배치와 정합) → 앞서 논의된 "출력 로그 패널" 아이디어가 여기로 수렴.
- **신규 ID(제안)**:
  - **FR-047** (SES · Should) 터미널 출력 캡처 버퍼·라우팅
  - **FN-SES-11** 캡처 버퍼 적재·편집·대상 주입 (캡처=FN-TRM-03 · 주입=FN-SES-04 재사용)
  - **SC-24** 출력 캡처 버퍼 패널 (소스 선택 · 버퍼 편집 · 대상 선택 · 주입)
  - **ENT-019** (신규 [R] 런타임) `output_capture_buffer { source_as, content(편집 가능), captured_at }`
- **08과의 관계**: 08의 캡처(`ITerminalSession` 출력 이벤트)가 FR-047의 **입력원**. 08 = 기반(캡처+주입), FR-047 = 그 위 버퍼·가공·라우팅 오케스트레이션.

## 4. 구현 순서 (스펙 확정 후)

```
[스펙 통합] FR-046(rename)·FR-047(출력 라우팅)·FN-TRM-16·FN-SES-11·SC-23·SC-24·BS-023·ENT-004·ENT-019 델타 반영(SSOT)
   │
   ▼
1. 컨텍스트 메뉴(SC-23) — 트리/pane 우클릭 → 명령실행·종료·이름변경   ◀ 사용자 지시: 선행
   + 트리 인라인 rename(SC-07 확장)
   │  (Interfaces/ITerminalSession 도입 — 08과 공유 계약)
   ▼
2. 08 명령 주입 + 출력 캡처 기반 (FR-014·002 · ITerminalSession 구현)
   │
   ▼
3. 출력 캡처 버퍼·라우팅 (FR-047 · 캡처 버퍼 패널 SC-24 · A출력→편집→대상 주입)
   │
   ▼
4. 이름 변경 마무리(FN-TRM-16) + 종료/재시작(FN-SES-05·06·10, 09 연계)
   │
   ▼
각 단계 빌드 0/0 검증 → 런북 역산출(08 상세화·출력 라우팅·rename 런북)
```

- 컨텍스트 메뉴의 "명령 실행"이 08 주입의 사용자 진입점이라, 1↔2는 `ITerminalSession` 계약으로 묶인다.
- "종료"는 09(세션 수명) 블루프린트와 연결 — SC-23이 그 진입 표면.
